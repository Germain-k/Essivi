# Application mobile livreur

Responsable : Meruem — Flutter recommandé (même stack que `mobile-client/` pour partager les conventions).

Pour initialiser le projet dans ce dossier :

```powershell
flutter create --org com.essivi --project-name essivi_livreur --platforms android,ios .
```

Cahier des charges : §5.4 (fonctions, mode hors ligne, GPS) et §10.3 (écrans).
L'API à consommer est décrite dans `docs/api/openapi.json`.
